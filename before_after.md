# before_after

## 1) Главная: CTA-фокус

Локация: `docs/index.md`

До:
- `Быстрый старт`, `Руководство`, `Скачать` (3 CTA на первом экране)

После:
- `Начать установку`, `Узнать диагностику` (2 CTA)

Эффект:
- Меньше когнитивной перегрузки, яснее первичный путь.

## 2) Главная: onboarding

Локация: `docs/index.md`

До:
- Не было сценарного блока “сделай X за Y шагов”.

После:
- Добавлен блок `Запусти за 3 шага` со статусами `Готово/Выполняется/Нужно внимание`.

Эффект:
- Быстрее переход от “чтения” к действию.

## 3) Главная: pipeline-визуализация

Локация: `docs/index.md`

До:
- Нет компактной схемы “как течёт поток”.

После:
- Добавлена схема `Input → Stream Hub → Output`.

Эффект:
- Быстрее формируется ментальная модель системы.

## 4) Установка: HTTPS-first

Локация: `docs/quick-start/installation.md`

До:
- В ряде примеров для CentOS фигурировал `http://` без сильного акцента на аварийность.

После:
- Команды по умолчанию переведены на `https://`.
- `http://` оставлен только в предупреждениях как fallback.

Эффект:
- Снижение security-риска и единый безопасный baseline.

## 5) Установка: безопасный запуск installer

Локация: `docs/quick-start/installation.md`, `docs/manual/security.md`

До:
- Недостаточно явно описан режим “скачать -> посмотреть -> запустить”.

После:
- Добавлен отдельный блок с локальным запуском installer.

Эффект:
- Повышение доверия и воспроизводимости установки.

## 6) Запуск: структура шага

Локация: `docs/quick-start/run.md`

До:
- Короткий список команд без контекста результата.

После:
- Формат “Зачем / Что нужно / Что получите / Как проверить”.

Эффект:
- Меньше ошибок первого запуска и лучше предсказуемость.

## 7) FAQ: инцидентное чтение

Локация: `docs/faq.md`

До:
- Плоский длинный список вопросов/ответов.

После:
- Добавлены “быстрый ответ за 1 минуту” и аварийный чек-лист.
- Вопросы переведены в раскрывающиеся блоки.

Эффект:
- Быстрее найти ответ под нагрузкой.

## 8) Troubleshooting: expected outputs

Локация: `docs/manual/troubleshooting.md`

До:
- Общие советы без чёткого порядка и критериев успеха.

После:
- Пошаговый 8-пунктовый чек-лист с expected outcomes.

Эффект:
- Сокращение времени диагностики и повторных обращений.

## 9) Code copy: обратная связь

Локация: `docs/javascripts/extra.js`, `docs/stylesheets/extra.css`

До:
- Нет явного короткого статуса после copy.

После:
- После клика по copy-кнопке временно показывается состояние `Скопировано`.

Эффект:
- Меньше ложных повторных кликов и ошибок копирования.
