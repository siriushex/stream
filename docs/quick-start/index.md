# Быстрый старт

Этот раздел нужен, чтобы быстро поднять Stream Hub и получить первый рабочий канал.

## Что вы сделаете

1. Установите Stream Hub.
2. Запустите Web UI/API на нужном порту.
3. Создайте stream и проверьте, что есть `ONLINE` и `bitrate`.

## Что нужно

- Linux‑сервер и доступ `sudo`.
- Свободный порт для Web UI.
- Адрес входного потока (`udp://...`, `http://...`, `https://...`, `...m3u8`, `...mpd`).

## Что получите

- рабочий stream с входом и выходом,
- понятную базовую диагностику,
- готовую основу для следующих каналов.
