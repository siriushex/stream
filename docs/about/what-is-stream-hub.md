# Что такое Stream Hub

**Stream Hub** — это платформа управления вещанием для IPTV/OTT задач:

- приём входов (`UDP`, `HTTP-TS`, `HLS`, `DASH`),
- маршрутизация и relay потоков,
- backup/failover и контроль стабильности,
- управление через Web UI и API,
- транскодирование в профиле `FULL`.

## Для чего используют Stream Hub

- быстро поднять вещание на сервере Linux,
- собрать предсказуемый pipeline `input -> stream -> output`,
- контролировать состояние каналов (`ONLINE`, bitrate, логи),
- автоматизировать операции через API.

## Позиционирование продукта

Stream Hub продвигается как самостоятельный продукт и бренд.  
Технологически часть решений опирается на практики экосистемы Astra/Flussonic, но рабочая модель, интерфейс и документация оформлены как отдельная платформа Stream Hub.
