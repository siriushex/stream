# Stream Hub Monitoring

**Stream Hub Monitoring** помогает держать вещание под контролем: быстро видеть деградации, находить причину проблем и сокращать время простоя.

## Что отслеживается

- состояние входа и канала: `ONLINE/OFFLINE`,
- текущий `bitrate` и его провалы,
- `uptime` канала и частота рестартов,
- события failover и ошибки обработки.

## Практическая польза

1. быстрее обнаруживаются проблемы с input и сетью,
2. оператор видит приоритет критичных каналов,
3. проще доказать стабильность и выполнить SLA.

## Где смотреть в Stream Hub

- Dashboard: сводное состояние потоков,
- Analyze/Log: причины ошибок и деградации,
- Observability: технические метрики и operational контекст.

## Рекомендации для стабильности

- держите polling и алерты в разумном диапазоне,
- отдельно отслеживайте `bitrate=0` и частые переключения input,
- используйте backup input для критичных каналов.
