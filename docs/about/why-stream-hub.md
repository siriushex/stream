# Почему Stream Hub

## Что важно в production

Для вещания обычно критичны три вещи:

1. **Стабильность потока** под сетевыми сбоями.
2. **Прозрачное управление** через UI и API.
3. **Предсказуемая эксплуатация**: логи, диагностика, сервисный запуск.

Stream Hub сфокусирован именно на этих задачах.

## Нейтральное сравнение подходов

| Критерий | Stream Hub | Типичный закрытый стек |
|---|---|---|
| Бренд и документация | Единый бренд Stream Hub | Часто привязан к вендору |
| Развёртывание | installer + source режим | Обычно vendor-specific |
| UI + API | Встроенные и документированные | Зависит от версии/лицензии |
| Диагностика | Чек-листы и operational docs | Часто фрагментарно |
| Переход с legacy-сценариев | Поддерживаются Astra-подобные паттерны | Может требовать миграции без совместимости |

## Про Astra и Flussonic

- Stream Hub — самостоятельный продукт.
- Astra/Flussonic упоминаются как ориентир сценариев и совместимости терминов.
- Документация не обещает “полную идентичность”, только фактическую поддержку заявленных функций Stream Hub.

## Что выбрать на старте

- Нужен надёжный relay без транскода: профиль `LITE`.
- Нужен транскод и ladder-профили: профиль `FULL`.

Подробнее: [Build profiles (FULL/LITE)](../manual/build-profiles.md).
