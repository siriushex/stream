# Stream Hub API

**Stream Hub API** нужен для автоматизации операций с потоками и интеграции с внешними сервисами мониторинга/управления.

## Типовые сценарии API

- массовое управление каналами,
- проверка статуса stream и health,
- автоматическое применение конфигураций,
- интеграция с внутренними панелями и tooling.

## Что даёт API в production

- меньше ручных операций в UI,
- воспроизводимые изменения через скрипты,
- быстрые реакции на инциденты и деградации.

## Практический путь

1. Включить защищённый доступ (auth + сеть).
2. Проверить базовые endpoint и права.
3. Использовать API в пайплайне деплоя и мониторинга.

Подробности по endpoint: [API reference](../manual/api.md).

## Совместимость сценариев

API Stream Hub закрывает основные задачи управления и мониторинга вещания.  
Упоминания Astra/Flussonic используются в документации только как контекст совместимых сценариев, без заявлений полной идентичности API.
