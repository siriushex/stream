# Stream Hub для IPTV

Stream Hub решает практическую задачу IPTV-оператора: стабильно принимать входы и отдавать потоки в нужном формате без лишней сложности.

## Ключевые возможности для IPTV

- **Relay и маршрутизация**: `UDP`, `HTTP-TS`, `HLS`, `DASH`.
- **Надёжность**: backup input, failover, базовая диагностика.
- **Контроль в реальном времени**: статус канала, bitrate, лог ошибок.
- **Управление**: Web UI для операторов + API для автоматизации.
- **Транскодирование (FULL)**: когда нужен пересчёт профилей, а не только pass-through.

## Типовой сценарий

1. Добавить `input` канала.
2. Добавить `output` для доставки.
3. Проверить `ONLINE` и bitrate.
4. Подключить backup и диагностику на случай проблем.

## Stream Hub и “альтернативы”

Если вы ищете `flussonic alternative`, `udp relay server`, `iptv stream relay` или `hls/http-ts relay`, Stream Hub закрывает этот класс задач в открытой и управляемой модели.

Упоминания Astra/Flussonic используются в документации только как контекст совместимых/наследуемых сценариев, а не как основной брендинг.
