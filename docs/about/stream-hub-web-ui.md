# Stream Hub Web UI

**Stream Hub Web UI** — это операторская панель для ежедневной работы с потоками без ручного редактирования конфигов.

## Что можно делать в Web UI

- создавать и редактировать `stream` каналы,
- настраивать `input` и `output`,
- смотреть статус `ONLINE/OFFLINE`, `bitrate`, uptime,
- запускать диагностику и быстро находить причину проблем,
- управлять пользователями и системными настройками.

## Для кого полезно

- NOC и дежурные инженеры,
- IPTV/OTT команды с большим числом каналов,
- операторы, которым нужен быстрый контроль состояния в браузере.

## Почему это важно

Web UI сокращает время между обнаружением проблемы и действием:

1. видно текущий статус канала,
2. видно ошибки и деградацию,
3. можно сразу применить изменение и проверить результат.

## Безопасный доступ

- включайте авторизацию для публичных окружений,
- ограничивайте доступ по сети и ролям,
- используйте HTTPS для доступа к панели.

Подробнее: [Безопасность](../manual/security.md).
