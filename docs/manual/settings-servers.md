# Settings → Servers

Servers — это список внешних серверов, которые Stream Hub может использовать в интеграциях.

Обычно сюда добавляют:

- адрес,
- порт,
- логин/пароль (если требуется),
- тип сервера (если есть выбор).

## Для чего нужно

- быстрый тест доступности/логина,
- просмотр списка удалённых стримов (каналов),
- удобное хранение параметров для нескольких площадок.

Если вы не используете внешние серверы — этот раздел можно пропустить.

## Формат Address (host)

Поддерживаемые варианты:

- `http://HOST` или `https://HOST`
- `http://HOST/base_path` (base_path будет автоматически добавлен ко всем API путям)
- `HOST:PORT`
- `HOST:PORT/base_path`

Если `Port` заполнен отдельно, он будет использован только когда порт не задан в `Address`.

## TLS (HTTPS) и self-signed сертификаты

Если сервер использует `https://` и сертификат self-signed (или на хосте устаревший CA bundle), Test/Pull/Import могут падать
с TLS ошибкой. В этом случае можно включить `insecure` (skip certificate check) в параметрах сервера.

## Ошибки

- `login failed (403)` обычно означает, что удалённый сервер отверг логин/пароль или запрещает логин по политике доступа.
- `health check failed (...)` означает, что сервер недоступен или не отвечает ожидаемым health endpoint'ам.

## Remote streams (каналы)

Кнопка `Streams` загружает список стримов с удалённого сервера по API и показывает их в модальном окне.
Список read-only: для переноса конфигурации используйте `Pull streams` или `Import config`.
