# Settings → Servers

Servers — это список удалённых инстансов `Stream`/`Astra legacy` для управления по API (без импорта конфигов в локальный инстанс).

Обычно сюда добавляют:

- адрес,
- порт,
- логин/пароль (если требуется),
- тип сервера (если есть выбор).

## Для чего нужно

- Test подключения (доступность API, тип API, версия, авторизация),
- просмотр и мониторинг удалённых стримов,
- удалённые действия и редактирование стримов через API (`CRUD + runtime actions`),
- удобное хранение параметров для нескольких площадок.

Если вы не используете внешние серверы — этот раздел можно пропустить.

## Формат Address (host)

Поддерживаемые варианты:

- `http://HOST` или `https://HOST`
- `http://HOST/base_path` (base_path будет автоматически добавлен ко всем API путям)
- `HOST:PORT`
- `HOST:PORT/base_path`

Если `Port` заполнен отдельно, он будет использован только когда порт не задан в `Address`.

## TLS (HTTPS) и self-signed сертификаты

Если сервер использует `https://` и сертификат self-signed (или на хосте устаревший CA bundle), Test/Streams могут падать
с TLS ошибкой. В этом случае можно включить `insecure` (skip certificate check) в параметрах сервера.

## Ошибки

- `login/password incorrect` означает ошибку авторизации на удалённом API.
- `http NNN: ...` показывает реальный статус и текст ошибки удалённого API.
- `no response/timeout` обычно означает сетевую проблему между инстансами.

## Remote streams (каналы)

Кнопка `Streams` загружает список стримов с удалённого сервера по API и показывает их в модальном окне.
Доступны:

- `Open` (открыть удалённый web/player),
- `Edit` (открыть локальный editor в remote mode),
- `Enable/Disable`,
- `Restart`,
- `Switch input` (если поддерживается выбранным API типом),
- `New remote stream` (создание на удалённом инстансе).

UI показывает capability badges, чтобы оператор видел доступные действия для текущего API типа.

## Мониторинг и обновление

- активная модалка Streams: адаптивно `1–5s` (`1s` при выбранном проблемном стриме/после действий, иначе `5s`),
- раздел Servers в фоне (модалка закрыта): обновление раз в `120s`,
- backoff при ошибках:
  - активный режим: `10s → 20s → 40s → 60s`,
  - фоновый режим: `240s → 480s`,
- после первого успешного запроса backoff сразу сбрасывается к базовому интервалу.

## Legacy import

`Pull streams` и `Import config` считаются legacy-путём и в обычном UI скрыты.
Backend endpoints `/api/v1/servers/pull-streams` и `/api/v1/servers/import` выключены по умолчанию и возвращают `410 Gone`.
Для временного включения установите `settings.servers_import_enabled=true`.
